#  Personal Profile Website — Ega Risqi Putra.S

Website sederhana berbasis **Laravel + Tailwind CSS** yang menampilkan data diri dengan tampilan modern dan interaktif.  
Proyek ini dibuat sebagai latihan pengembangan web dan desain UI/UX.

---

##  Fitur Utama
- Tampilan profil dengan video bulat sebagai avatar.
- Tombol **View More** untuk menampilkan data tambahan secara dinamis.
- Footer dengan copyright dan tautan ke profil GitHub.
- Desain responsif menggunakan Tailwind CSS.
- Animasi halus saat card diperluas.

---

##  Teknologi yang Digunakan
| Komponen | Deskripsi |
|-----------|------------|
| **Laravel** | Framework PHP untuk backend dan routing. |
| **Tailwind CSS** | Styling cepat dan fleksibel untuk tampilan modern. |
| **JavaScript** | Mengatur interaksi tombol dan animasi expand. |
| **HTML5 Video** | Menampilkan video profil berbentuk lingkaran. |
